**Spec:** [SCP_R2_REGISTRY_HOSTING.md](../SCP_R2_REGISTRY_HOSTING.md)

## Fetch from an SCP node

Use `scp_fetch_registry` ([R4 spec](../SCP_R4_FETCH_REGISTRY.md)) with the URL above and an allowlisted host.
